## Causa del fallo del arranque cotidiano upstream

Al ejecutarse mediante el loader glibc, `process.execPath` es la ruta del loader. En el source del tag, `packages/cli/src/util/process.ts` hace que `selfCommand()` devuelva solo `process.execPath` cuando el runtime no se identifica como Bun o Node. El arranque normal usa `packages/cli/src/services/service-config.ts`, que agrega `serve --service`; relanza el loader sin el binario `opencode` ni `--library-path`, y el loader interpreta `serve` como el archivo ELF.

El runner inicia el ELF como `loader --library-path ... opencode serve --port 0` y conecta el cliente con `--server`. La contraseña se genera para esa invocación y no se imprime; el runner cierra y espera su proceso servidor al terminar. Esta ruta conserva la invocación cotidiana sin argumentos. No se ensayaron parches binarios, `patchelf`, runtimes alternativos, paquetes nuevos ni modificaciones del loader.

## Límites y decisión

- La evaluación integrada confirma el digest, la versión, las rutas, la configuración y `session list`; abrió la TUI real, cuyo cierre no quedó aprobado. No instaló v2 ni modificó el catálogo.
- No se instalaron ni actualizaron v1 o v2. No se ejecutó `verify.sh` contra una instalación real.
- No se hicieron solicitudes a proveedores ni a Internet desde OpenCode. El único tráfico de la CLI fue contra `127.0.0.1`; la descarga del tarball fue la operación de red autorizada.
- Quedan sin aprobar: cierre normal/teclas/resize de TUI mediante runner, herramientas de agente/subprocesos locales, DNS/TLS externo, prompt efectivo de permisos, mediciones de rendimiento y comparación con v1. Las pruebas negativas de configuración/plugins/ancestros sí pasaron en el evaluador integrado.
- La evaluación reciente limpió el temporal y no dejó procesos del candidato. No se modificaron instalaciones ni datos privados.

No promover este candidato hasta cerrar las pruebas pendientes de aislamiento, política y TUI con el runner integrado y el artefacto exacto. `--standalone` queda fuera del contrato de uso habitual.
