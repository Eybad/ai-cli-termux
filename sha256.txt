# sha256.txt — Tarball checksums by tool
#
# Format:   <tool>/<tag>[:<arch>]  <checksum>
#           <arch> optional (arm64/amd64) for architecture-specific pins.
#
# Role:
# - MANDATORY for tools with CHECKSUM_SOURCE=hashfile: only source of version
#   and checksum (vendors without JSON manifests or public asset digests).
#   Without an entry, installation fails closed.
# - OPTIONAL for remaining tools: version and checksum resolve automatically
#   in a fail-closed manner (release_digest via GitHub API, or vendor manifest).
#   If a pin exists for the target tag, install.sh prioritizes it over remote digests.
#
# Adding a new checksum:
#   TAG=v1.18.9
#   TOOL=opencode
#   curl -fLO "https://github.com/anomalyco/opencode/releases/download/$TAG/opencode-linux-arm64.tar.gz"
#   sha256sum opencode-linux-arm64.tar.gz
#
# Verify attestation before adding (requires authenticated gh):
#   gh attestation verify <tarball> \
#     --repo <user>/<repo> --predicate-type <predicate>
#
# Note:
# patchelf modifies ELF binaries after extraction; installed binary hashes
# never match the upstream tarball. verify.sh checks against manifest.txt,
# not this file. This file covers the downloaded archive only.
#
# Entries:
# opencode — https://github.com/anomalyco/opencode/releases
# Optional pin: default installation uses the GitHub API digest.
